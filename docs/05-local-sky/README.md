# 05: Your local sky

Everything so far computed where things are *in space*. This module turns that
into where things are *from where you stand*, the first time your latitude
genuinely changes the answer.

## Lessons

| # | Lesson | What you get |
|---|---|---|
| 1 | [Which way am I facing?](which-way-am-i-facing.md) | **The lab**, find north without a compass |
| 2 | [Altitude and azimuth](altitude-and-azimuth.md) | The local coordinate system |
| 3 | [Why your latitude matters](why-latitude-matters.md) | The sky from six places at once |
