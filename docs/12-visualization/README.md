# 12: Visualisation

> **Status: planned.** This module is scoped but not yet written. The scope
> below is the commitment; it is here so you can see where the curriculum is
> going and tell us if the plan is wrong.

Seeing the geometry, in 2D and then in 3D.

## Planned lessons

- Plotting orbits from the elements you already have
- Sky charts for your own horizon
- Animating a lunar month
- 3D: the Earth-Moon system to scale
- Making an animation you can show someone else

## Prerequisites

- Module 08
- any earlier module you want to draw

## Intended approach

Optional dependencies only; the core install stays dependency-free. Likely matplotlib for 2D, with a browser-based 3D option so nothing needs installing.

queue. Better still, write a lesson: see
